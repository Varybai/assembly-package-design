## 2. 默认继承的决定

- 功能描述与 UID 分离；固定版本不被覆盖。
- 定义、实例和运行记录分离；组合关系可追溯。
- 模块可按需下钻；原子边界由本领域定义。
- 检索候选须经精确条件筛选；证据保留适用范围。
- 内部验证与实例环境检查分开，缓存覆盖因果依赖。
- 原生文件与派生投影分别管理，不丢失未知字段。
- 数据和缓存位于消费项目；代码从安装包解析。
- Pi 工具、Skill、命令、配置和缓存使用本包命名空间。
- 安装、setup、构建和发布独立；失败/取消状态真实。

偏离上述决定时，附对应 Cxx 规则和决策记录。无需复制整份宪章。
